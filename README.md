# Arcaphyte Weaver

Official public installer downloads for Arcaphyte Weaver.

[Download for Windows, macOS, or Linux](https://www.arcaphyte.com/weaver/download/) · [Latest release](https://github.com/Arcaphyte/Arcaphyte-Weaver/releases/latest)

Install Weaver, then sign in with your Arcaphyte account and Weaver license. Manage your account and up to five activated devices at [arcaphyte.com](https://www.arcaphyte.com/account/).

Application source is maintained separately in a private repository. This repository contains release downloads and public release information.

Each release includes SHA-256 checksums and signed updater downloads. See the release notes for platform installation details.
